# Malaria Detection Using Deep Learning

A deep learning project that classifies microscopic blood cell images into two categories: Parasitized and Uninfected. The project uses a Convolutional Neural Network (CNN) built with TensorFlow and Keras to learn visual patterns from blood cell images and predict whether malaria parasites are present.
The project covers the complete deep learning workflow, including data preparation, preprocessing, augmentation, model development, training, evaluation, and experiment tracking.
The project integrates Weights & Biases to track experiments and training performance.The notebook logs model configuration, training metrics, and test evaluation results.
The experiment dashboard can be accessed here: **[View Malaria Detection on Weights & Biases](https://forge.coreweave.com/wandb/vinaybelieve55-rgukt-ongole/Malaria-Detection?nw=nwuservinaybelieve55)**
